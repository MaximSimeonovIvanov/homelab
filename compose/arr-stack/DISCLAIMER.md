# Disclaimer

This directory contains configuration files for a self-hosted music pipeline
(Navidrome, Lidarr, qBittorrent, Prowlarr, slskd). These tools are deployed
strictly for educational purposes as part of a homelab learning project.

The purpose of this setup is to understand how download automation, media
management pipelines, and self-hosted streaming services work — not to obtain
or distribute copyrighted material.

Legitimate uses of this stack include:

- **Linux ISOs** — most Linux distributions are distributed via BitTorrent
  officially (Ubuntu, Fedora, Debian, etc.)
- **Freely licensed music** — Creative Commons and other openly licensed
  releases that permit free distribution
- **Public domain content** — recordings and works where copyright has expired

The author does not condone piracy or the unauthorized downloading of
copyrighted material. No pirated music, films, software, or any other
copyrighted content has been obtained using this setup.
